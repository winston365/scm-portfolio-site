# 기술 스택

## SCM 업무 도구

| 분류 | 도구 | 활용 |
|------|------|------|
| ERP | ECOUNT ERP | 발주·재고·매입·매출 관리 |
| 스프레드시트 | Excel (고급) | 피벗·함수·데이터 분석 |
| 매크로 | Excel VBA | 반복 업무 자동화 |
| 문서 관리 | Obsidian | 업무 WIKI 구축, 지식 관리 |

## 업무 자동화 도구

| 도구 | 숙련도 | 활용 실적 |
|------|--------|----------|
| **Python** | 중급 | 3사 업무 자동화 프로그램 |
| Pandas | 중급 | 발주·납기 데이터 분석/가공 |
| OpenPyXL | 중급 | Excel 파일 자동 생성/수정 |
| Tkinter | 중급 | 사용자 입력 UI 구현 |
| PyInstaller | 중급 | 단일 실행파일 배포 |
| **Excel VBA** | 고급 | 기존 업무 매크로 유지보수 |

## 환경규제 시스템

| 시스템 | 역할 |
|--------|------|
| IMDS/CAMDS | 재료 데이터 등록 |
| ICP DATA | RoHS 분석성적서 관리 |
| G-SRM (삼성전자) | 분쟁광물 등록 |
| HSMS/SCS (LG이노텍) | 환경규제 대응 |
