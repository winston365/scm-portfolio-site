# 업무 자동화 성과 (직접 기획·개발)

> **총 연간 절감: 302시간 12분** | **포상금: 350만원** (2024년)

## 역할

외자(REP)팀 소속으로, **타 담당자(내자팀) 고객사 업무 자동화를 직접 기획·개발**했습니다.

**개발 환경 특성**:
- **폐쇄망 환경**에서도 구동 가능한 **단일 실행파일(.exe)** 개발
- PyInstaller로 패키징하여 **사내 배포** (비개발자 담당자도 즉시 사용 가능)
- 외부 라이브러리 의존 없이 순수 Python + Pandas/Tkinter 구성
