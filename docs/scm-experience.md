## 납기 관리

### 긴급 대응 실적

- **요코가와향 약 100건** 긴급 납기조정을 결품 없이 처리
- 중복발주 5건 처리 (2건 캔슬, 2건 변경, 1건 매입 합의)
- Backlog 추적 시스템으로 실시간 관리

### 발주 프로세스 체계화

요코가와 발주서 처리 5단계 체계 수립:

1. PDF 분할
2. OCR 추출
3. 기본시트 입력
4. 검토
5. 발주
